# Лендинг психоаналитического консультанта

**Живой сайт:** https://deniskazakov1976-glitch.github.io/kazakova-psy/
GitHub Pages, ветка `main`, корень репозитория. Пуш в `main` = публикация через 1–2 минуты.

Одностраничный сайт на чистом HTML/CSS/JS: без сборки, без бэкенда, без зависимостей.

## Структура

```
index.html        — лендинг
privacy.html      — политика обработки персональных данных (152-ФЗ)
404.html          — страница ошибки
styles.css        — все стили (два слоя: базовый и «Слой 2» после консилиума)
app.js            — меню, модальное окно, форма заявки, cookie-согласие
robots.txt        — индексация (папка .council/ закрыта)
sitemap.xml       — карта сайта
images/           — портрет в AVIF/WebP/JPEG (380w и 760w), иконки, og-image
tests/            — автотесты (см. ниже)
```

## Как принимаются заявки

Форма `#mainBookingForm` не имитирует отправку. Работают два пути:

1. **Вебхук.** Если в `index.html` задан `ANALYTICS_CONFIG.formEndpoint`
   (например, `https://formspree.io/f/xxxx`), заявка уходит POST-запросом `application/json`.
   Успех показывается только при `response.ok`.
2. **Telegram.** Если `formEndpoint` пустой, форма собирает текст заявки и открывает
   чат `t.me/KazakovaEvgeniya` с готовым сообщением — человеку остаётся нажать «Отправить».

В обоих случаях экран не обещает того, чего не произошло. Ошибка доставки показывает
честное сообщение и ссылку в Telegram.

## Если подключите свой домен

1. Создайте файл `CNAME` в корне с доменом (например, `kazakova-psy.ru`).
2. У регистратора: `A`-записи на IP GitHub Pages либо `CNAME` на
   `deniskazakov1976-glitch.github.io`, затем включите HTTPS в настройках Pages.
3. Замените базовый адрес в четырёх файлах: `index.html` (canonical, og:url, og:image,
   twitter:image, JSON-LD), `privacy.html`, `sitemap.xml`, `robots.txt`.
   Тест `TestSiteUrl` покажет, если что-то забыто.
4. Поменяйте «Адрес сайта» в счётчике Метрики, иначе визиты перестанут засчитываться.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Два набора:

- `tests/test_static.py` — разметка, юридические блоки, SEO, контраст (WCAG AA),
  защита от регрессий в CSS, гигиена репозитория. Работает без браузера.
- `tests/test_browser.py` + `tests/harness.html` — реальный движок Edge/Chrome:
  отсутствие горизонтальной прокрутки на 320–1440 px, CTA в первом экране,
  cookie-бар не перекрывает кнопку, бургер-меню, фокус в диалоге, отправка формы
  в Telegram с текстом заявки, FAQ без JS.
- `tests/test_analytics.py` + `tests/analytics.html` — Яндекс.Метрика: тег не грузится
  до согласия, после «Принять» подключается счётчик `112744330` с `webvisor: false`,
  цели уходят с нужными именами и без персональных данных, отказ оставляет аналитику
  выключенной. Сеть блокируется (`MAP * ~NOTFOUND`), поэтому тестовые визиты
  не попадают в настоящий счётчик.

Требуется Python 3.10+ и установленный Edge или Chrome. Без браузера
браузерные тесты помечаются как skipped.
