# Инструкция по настройке веб-аналитики и рекламы

Этот документ содержит пошаговое руководство по активации аналитики и рекламных пикселей на вашем лендинге.

---

## 1. Яндекс.Метрика (Основная аналитика)

### Шаг 1. Создание счётчика в Яндекс.Метрике
1. Перейдите на сайт [metrika.yandex.ru](https://metrika.yandex.ru/) и войдите под вашим Яндекс-аккаунтом.
2. Нажмите жёлтую кнопку **«Добавить счётчик»**.
3. Заполните поля:
   - **Имя счётчика:** `Евгения Казакова — Лендинг`
   - **Адрес сайта:** укажите ваш домен (например, `kazakova-psy.ru` или адрес хостинга).
   - **Часовой пояс:** `Пермь (UTC+5)` (или ваш рабочий).
   - Включите переключатель **«Вебвизор, карта скроллинга, аналитика форм»** (обязательно включить!).
4. Примите условия соглашения и нажмите **«Создать счётчик»**.
5. Скопируйте цифровой **номер счётчика** (8-значное число, например: `98765432`).

### Шаг 2. Вставка номера счётчика в код сайта
Откройте файл `index.html` и в строке ~30 найдите блок:

```javascript
window.ANALYTICS_CONFIG = {
  // 1. Яндекс.Метрика: номер счётчика (например, '98765432')
  ymId: 'XXXXXXXX', // <-- Замените XXXXXXXX на ваш номер (например: '98765432')
...
```

Замените `'XXXXXXXX'` на ваш номер. Сохраните файл. Счётчик начнёт работать сразу после загрузки файла на хостинг.

## 2. Настройка целей в Яндекс.Метрике

Чтобы видеть, сколько людей нажимают кнопки и отправляют заявки, настройте в интерфейсе Метрики **цели типа «JavaScript-событие»**:

1. В кабинете Метрики перейдите в раздел **«Настройка»** (в левом меню) -> вкладка **«Цели»**.
2. Нажмите **«Добавить цель»**.
3. Выберите тип условия: **«JavaScript-событие»**.
4. Добавьте по очереди следующие цели:

| Название цели в Метрике | Идентификатор цели (вставить ровно так!) | Что фиксирует |
| :--- | :--- | :--- |
| **Клик «Записаться»** | `booking_click` | Нажатие кнопки «Записаться» в шапке, Hero, условиях или модалке |
| **Переход в Telegram** | `telegram_click` | Клик по любой кнопке или ссылке Telegram |
| **Переход в WhatsApp** | `whatsapp_click` | Клик по любой кнопке или ссылке WhatsApp |
| **Отправка заявки** | `form_submit` | Успешное заполнение и отправка формы записи |
| **Опрос по диссертации** | `dissertation_survey_click` | Переход к анкете исследования для мам малышей |

> [!NOTE]
> В параметры целей сайт автоматически передаёт место клика (`location: "hero"`, `"header"`, `"contacts"`, `"modal"`, `"footer"`), поэтому в отчётах Метрики вы сможете детально смотреть, из какого именно блока чаще приходят клиенты.

## 3. Как проверить работу целей прямо сейчас (до запуска рекламы)

Код уже полностью готов и снабжен отладочным режимом. Вы можете проверить его прямо на компьютере:

1. Откройте `index.html` в браузере (Chrome / Firefox / Edge / Safari).
2. Нажмите клавишу `F12` (или правой кнопкой мыши -> *«Просмотреть код»*) и перейдите во вкладку **Console** («Консоль»).
3. Нажмите на сайте любую кнопку «Записаться», кликните на Telegram или отправьте тестовую форму.
4. В консоли сразу появится цветная строчка:
   ```text
   [Цель аналитики] booking_click {location: "hero"}
   [Цель аналитики] telegram_click {location: "header"}
   [Цель аналитики] form_submit {topic: "relationships", format: "online"}
   ```
Это подтверждает, что при появлении реального номера счётчика эти данные автоматически будут улетать в Яндекс.Метрику.

### Проверка на рабочем сайте (с реальным счётчиком)
Добавьте к адресу сайта параметр `?_ym_debug=1`, например:
`https://vash-sait.ru/?_ym_debug=1`
В консоли браузера будут выводиться системные сообщения Яндекс.Метрики о доставке каждого события на сервера Яндекса.

## 4. Подключение рекламы (Яндекс.Директ)

Яндекс.Директ работает в связке с Яндекс.Метрикой автоматически:
1. Создайте рекламную кампанию в [direct.yandex.ru](https://direct.yandex.ru/) (Мастер кампаний или РСЯ / Поиск).
2. При создании кампании укажите ваш сайт — Директ автоматически найдёт привязанный счётчик Метрики.
3. В блоке **«Целевые действия»** (конверсии) выберите созданные цели:
   - Основная ценность: **«Отправка заявки» (`form_submit`)**
   - Дополнительная ценность: **«Переход в Telegram» (`telegram_click`)** и **«Переход в WhatsApp» (`whatsapp_click`)**
4. Это позволит включить автостратегию **«Оплата за конверсии»** или **«Максимум целевых визитов»**, чтобы рекламный бюджет расходовался только на тех пользователей, которые совершают целевое действие.

## 5. Дополнительно: Пиксели VK и Google Analytics 4

Если в будущем вы решите запустить рекламу во ВКонтакте или использовать GA4:

### Пиксель VK Рекламы:
1. Зайдите в кабинет [ads.vk.com](https://ads.vk.com/) -> раздел «Сайты» / «Пиксели» -> Создать пиксель.
2. Скопируйте ID пикселя (вид: `VK-RTRG-XXXXXX-XXXXX`).
3. Вставьте его в `index.html`:
   ```javascript
   vkPixelId: 'VK-RTRG-XXXXXX-XXXXX',
   ```
Пиксель сразу подключится и начнет собирать аудиторию посетителей для ретаргетинга.

### Google Analytics 4:
1. Создайте поток данных типа «Веб» в [analytics.google.com](https://analytics.google.com/).
2. Скопируйте идентификатор потока (вид: `G-XXXXXXXXXX`).
3. Вставьте его в `index.html`:
   ```javascript
   ga4Id: 'G-XXXXXXXXXX',
   ```
Все цели (`booking_click`, `telegram_click`, `whatsapp_click`, `form_submit`) автоматически отправляются и в GA4 через стандартный `gtag('event', ...)`.
